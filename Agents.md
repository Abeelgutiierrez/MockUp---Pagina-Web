# AGENTS.md

## Project

Fashion Texa corporate website redesign concept.

## Goal

Build a premium, navigable B2B apparel-sourcing website demo intended for a client presentation.

## Priorities

1. Visual quality
2. Navigation and UX
3. Responsive behavior
4. Accurate use of existing Fashion Texa information
5. Maintainable React architecture

## Critical rules

- Never invent company statistics, certifications, customers, factories, markets or sustainability claims.
- Use placeholders for unverified business data.
- This is not ecommerce.
- Do not add prices, cart or checkout.
- Avoid generic SaaS / Bootstrap / WordPress-template aesthetics.
- Reuse templates and structured data instead of duplicating page code.
- All important buttons and navigation items must work.
- The demo must remain functional without an Internet connection once assets are downloaded.
- Always run the build before considering a task complete.
- For visual changes, inspect the rendered result when browser tools are available.
