# Fashion Texa Website Concept

Premium multipage React demo for a B2B apparel-sourcing client presentation.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Routes

`/`, `/company`, `/capabilities`, `/products`, `/products/men`, `/products/women`, `/products/kids`, `/products/men/circular-knits`, `/products/men/woven`, `/products/women/circular-knits`, `/products/men/circular-knits/t-shirts`, `/sustainability`, `/contact` and a catch-all 404.

All critical media is stored locally under `public/images`. Site copy and structured product data live under `src/data`.
